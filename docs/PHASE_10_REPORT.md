# Phase 10 — 用户投稿与开发者中心交付报告

基线：`93738c139b5c8e04243d5b5757e30356147c7ddb`（用户已验收 Phase 9）。本阶段主题/Core **0.10.0**、schema **1.8.0**，仅新增 `author_claims`，共 **26 张 Core 表**。本报告仅覆盖 Phase 10 及明确执行的旧模块回归；不把历史 Final QA、Mock 或规划当成本轮真实验收。

## 实现范围

- 已验证原生用户投稿：草稿、提交、编辑、撤回、查看反馈；沿用私有 `aish_message`、受保护 postmeta 和原生 revisions。Contact/历史匿名投稿保持原记录，不按邮箱、旧 post_author 或同名 Skill 认领。
- 本地复用 GitHubClient 校验仓库根 URL、规范仓库身份和独立相对路径；相同仓库不同路径分别处理，空路径待确认。来源锁、请求指纹、CAS、事务及通知幂等；不触发 GitHub/AI/付费请求。
- 独立投稿和更新建议审核。Accepted 只接受进入后续流程；可随后受控关联最终资源。Skill、不可变版本和人工译文不被改写，公开链接仍由 PublicCatalog 门禁控制。
- 双语开发者公开主页、资料候选/批准快照、本人公开同意、审核历史、安全 PNG 头像、公开贡献。缺少对应译文返回可解释的不可用状态，只给真实存在的另一语言链接。
- Original Author、Repository Maintainer、Submitter 明确区分；人工证据核对、认领通过/拒绝/撤回/撤销/争议。认领不授予 Skill 管理权限；来源/修订变化后保守隐藏旧认领，需重新审核。
- 四类独立 WordPress 原生后台队列、能力、Nonce、审核备注与只读原稿、分页搜索及有限批量操作。经审核公开资料有独立 Title/Description/Canonical/hreflang/OG/Twitter；私有页面 noindex/no-store。
- 接入既有账户通知及隐私导出/擦除。原生删除和转交前隔离私人投稿/修订；分批清理证明和私人备注，不删除正式 Skill 或历史来源版本。

正式前台复用 Phase 7.5 白色、浅灰、深灰和陶土棕设计；原型没有修改。未开发 Phase 11 排行榜、Phase 12 分析或支付。

## 开发中发现并已修复

| 问题 | 修复与回归 |
| --- | --- |
| 原生 update_post_meta 会将 revision ID 重定向到父记录 | 使用原生 update_metadata 明确写子修订，真实子快照/父记录归属检查通过 |
| 更新建议调用 PublicCatalog 缺少过滤参数 | 补齐既有查询合同，合法更新建议真实双版本回归通过 |
| CPT 提前映射能力导致原生对象权限过滤漏过 | 同时检查带对象 ID 的映射后能力；全局配置能力保持正常，原生读/编辑/删除及 metadata 绕过回归通过 |
| Accepted 后无法追加最终资源关联 | 增加独立 CAS/权限受控结果关联操作，保持 accepted 状态与 Skill 发布门禁 |
| 审核反馈覆盖历史、硬修订上限阻断审核 | 内容/处理快照分离、追加历史和分页；保留字段/频率上限，不以修订总量阻止正常审核 |
| 列表关联资源超过 Catalog 单次24 ID限制 | 批量分块查询，保留公开门禁，真实多结果测试通过 |
| 认领原始材料语言误用为界面语言筛选 | 分开 display_locale 与原始语言筛选，切换语言仍能看到自己的全部认领 |
| 撤回同意或修改头像后的旧批准信息可能复现 | 公开快照与当前更严格的同意共同生效；重新 opt-in 要求新审核 |
| 原生写事务的缓存和外部副作用边界 | 提交/回滚后明确失效缓存并恢复调用方标志，事务内拦截 HTTP/wp_mail；真实阻断和回滚检查通过 |
| 隐私擦除在调用方暂停缓存失效时残留旧私有对象 | 显式清除缓存并恢复原标志；原生转交、审核人备注及大量修订擦除回归通过 |
| 多语言认领证明可能超过 TEXT 字节上限 | 使用紧凑 Unicode JSON、60 KB 写入前限制，不依赖 MySQL 截断 |
| 无效公开 handle 错报服务不可用及按钮间距 | 不可用 handle 返回404；修正作用域内按钮间距，未改变视觉体系 |

## 限制与未执行

- **真实 SMTP、收件箱送达、WPML、外部 GitHub/AI API 本轮未执行**；没有凭据/合法 WPML 包，不报告通过。用户给出的仓库和证据 URL 只做本地格式及既有数据核查，真实所有权须管理员核验。
- SEO 插件接口使用隔离 hook 检查；本轮未重新安装 Yoast/Rank Math 做真实插件兼容验收。其他账户/缓存插件、多站点、Firefox/Safari 和生产持续负载未验证。独立进程竞争通过不代表生产压测通过。
- 开发者页面暂不加入新的 Sitemap provider，以已公开 Skill 归属链接发现；私有页面始终排除。公开页暂用 no-store，优先即时撤回隐私。
- 当前设计每个 Skill 同时只有一条有效批准认领。来源或 Skill 审核修订变化后旧认领保守失效，管理员撤销后再申请/审核，不擅自继承。
- 投稿/认领结案后180日自动删除策略仍是待站点确定的保留政策，没有新增隐式清理任务。账户注销的隔离与批量擦除已实施；现有通知/工作流保留机制照常运行。
- 本轮未发现尚未修复的 P0/P1 问题；这是已执行范围的结论，不宣称全部外部依赖或后续阶段已经验收。
