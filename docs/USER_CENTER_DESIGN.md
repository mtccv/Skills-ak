## 2. 信息架构与权限

计划 URL 均在对应阶段实施后才可用；以下不是当前网站已存在的地址。

| 分区 | 计划入口 | 主要任务 | 访问条件 |
| --- | --- | --- | --- |
| 身份入口 | `/{lang}/register/`、`login/`、`forgot-password/`、`reset-password/`、`verify-email/` | 注册、验证、登录与恢复 | 访客或受限验证会话；敏感结果不公开索引 |
| 总览 | `/{lang}/account/` | 继续探索、处理待办、查看最近内容 | 本人登录；未验证时只显示验证及必要恢复界面 |
| 我的收藏 | `/{lang}/account/favorites/` | 搜索、筛选、取消收藏 | 已验证本人；列表始终私有 |
| 我的评价 | `/{lang}/account/reviews/` | 查看公开版/待审稿、编辑、撤回 | 已验证本人；所有修订属于同一用户与 Skill |
| 我的投稿 | `/{lang}/account/submissions/` | 保存草稿、补充、跟进审核、撤回 | 已验证本人；投稿正文及状态私有 |
| 开发者 | `/{lang}/account/developer/` | 认领、更新建议、申请公开档案 | 已验证本人；公开资料和认领分别审核 |
| 通知 | `/{lang}/account/notifications/` | 阅读结果、处理必要事项 | 本人；打开时再次检查对象所有权 |
| 设置 | `account/profile/`、`account/security/`、`account/privacy/` | 资料、语言、安全、数据权利 | 本人；安全操作要求近期认证 |

统一侧栏顺序：总览 → 我的收藏 → 我的评价 → 我的投稿 → 开发者中心 → 通知 → 账户设置。账户设置内采用资料、安全、隐私三个二级入口，通知偏好从通知页和设置同时可达。退出放在侧栏末尾；正式产品以 POST 执行，普通导航链接不直接注销。

访客从收藏等入口进入登录时，保留安全的站内目标；完成验证后返回仍公开的目标。目标已撤下则说明“该资源暂不可用”，不开放旧草稿。已验证用户仅操作本人对象；认领成功也不授予发布、采集、AI 或 WordPress 管理能力。无权读取他人私有对象时使用统一不可用提示，不泄露记录是否存在。

## 3. 布局与组件规范

沿用统一视觉 token：主色 `#7047EB`、悬停 `#5934C7`、正文 `#182134`、次级文字 `#596579`、背景 `#F6F7FB`、卡片 `#FFFFFF`、边线 `#DFE4ED`、成功 `#15734F`。字体使用系统 sans 与中文系统字体，不依赖远程字体。正文 15–16px，表单不小于16px，辅助文字不小于12px；大标题 30–36px，区块标题20–24px。卡片圆角16px、按钮10px，所有操作触点至少44×44px。

| 视口 | 网格与导航 | 内容与交互 |
| --- | --- | --- |
| 桌面 ≥1024px | 总容器最多1280px，侧栏240px、间隔24px、主内容 `minmax(0,1fr)`；全站页头保持品牌及语言导航 | Dashboard 欢迎区 → 状态摘要 → 收藏 → 贡献与通知；内容卡片优先2列，避免三列过窄 |
| 平板 768–1023px | 去除常驻侧栏，账户导航用原生可展开菜单，展开时2列入口 | 简短统计2列，卡片2列；表格换成卡片式行，不要求横向滚动 |
| 手机 <768px | 16–20px边距、主内容单列；账户菜单位于页标题上方，不用遮盖正文的固定底栏 | 简短统计保留2列，说明在组外；标题和操作分行，内容卡片与表单全宽，按钮可换行；通知时间放到正文下方 |

桌面侧栏可在足够高度下粘附；移动端不粘附长菜单。锚点滚动留出顶部空间；菜单展开不造成键盘焦点陷阱。长邮箱、标题、URL、错误信息可换行，不撑破320px视口。统计不是首要操作，不能让手机用户先滚动一屏才能到待办。

共享组件：账户身份块（默认几何/字母头像、显示名、验证状态）、账户导航、页面标题/说明/主操作、验证横幅、统计小卡、Skill 卡片、状态徽章、稿件列表行、事件时间线、通知行、表单字段、错误摘要、空状态、分页与危险操作确认。

状态徽章同时使用文字和图形：紫色=待处理/修改待审；薄荷=已验证/已批准；琥珀=需要补充/等待；中性=草稿/不可用/已撤回；红色=失败或拒绝。颜色不是唯一信息，禁止用成功绿色表示“提交待审”。

## 4. 注册、登录、验证与重置

认证页采用独立主卡，桌面宽440–480px；旁边可有简短价值说明，移动端只保留主卡。共享页头只展示品牌、语言和返回探索，不把复杂公开导航放在登录任务之前。每页一个 h1、明确主按钮、返回登录/注册的次级文字入口。

| 页面 | 字段与布局 | 反馈、异常与退出路径 |
| --- | --- | --- |
| 注册 | 邮箱、显示昵称、密码及可访问的显示/隐藏按钮、界面语言、必要条款确认；邮箱默认私有；营销订阅不勾选、不捆绑 | 行内校验与顶部错误摘要；密码强度用文字说明；统一结果不泄露邮箱是否已存在；重复点击期间禁用主按钮但保留返回入口 |
| 登录 | 邮箱、密码、忘记密码；支持密码管理器和粘贴，autocomplete=email/current-password | “邮箱或密码不正确”统一提示；会话失效返回登录；验证未完成进入受限验证页，不进入互动页 |
| 验证待完成 | 脱敏邮箱、检查邮件指引、重发、更换错误地址/恢复帮助、退出 | 建议24小时有效、重发至少间隔60秒；显示实际限频时间。仅队列接收显示“验证邮件已排队”，传输接受显示“已交给邮件服务”；不保证已送达 |
| 验证链接落地 | 简短确认说明与“确认验证邮箱”按钮 | GET 不自动消费令牌；确认提交后才显示真实结果。过期、已使用、无效、已被新链接替代分别给恢复入口；不在正文/分析/日志保留 token |
| 忘记密码 | 邮箱、发送重置指引、返回登录 | 统一“若该邮箱可用于恢复，我们会发送指引”；不据此确认账户存在；队列失败提供稍后重试且不假称发送成功 |
| 重置密码 | 新密码、必要的再次确认、显示/隐藏与强度反馈 | 使用 WP 原生重置规则；链接过期/无效回到恢复入口；真实成功后引导重新登录，令牌单次使用，敏感 URL 参数及时移除 |

表单标签始终可见，placeholder 不代替标签。必填/格式说明关联 `aria-describedby`，错误输入设 `aria-invalid`；提交错误聚焦摘要，摘要可跳转字段。提交中使用 `aria-busy`，状态用礼貌 live region；限流不清空非敏感字段。密码、令牌不写本地存储、分析或 URL；切换语言保留安全的任务上下文，不把密码或令牌复制到链接。

### 认证状态文案

| 中文 | English | 含义 |
| --- | --- | --- |
| 请先验证邮箱，开启收藏与投稿。 | Verify your email to unlock saving and submissions. | 指向未来已实现的功能；未上线阶段改为“完成账户验证” |

| 此链接已失效，请重新获取。 | This link has expired. Request a new one. | 提供重发或恢复入口，保留语言 |
| 操作过于频繁，请稍后再试。 | Too many attempts. Please try again later. | 不暴露内部限流标识 |
| 暂时无法确认发送结果。 | We cannot confirm the sending result yet. | 不把不确定发送自动当作失败无限重发 |

## 5. Dashboard

欢迎区只使用显示昵称，不露出登录名；头像默认本地字母或几何图形。验证状态与内容统计分开：已验证以小徽章显示，未验证以清楚的行动横幅替换主要内容。示例原型使用“Alex · 示例账户 / Alex · Example account”及“已验证 · 示例 / Verified · Example”；这不是认证成功证据。

内容优先级：

1. 当前需要用户处理的事项，如邮箱验证、补充投稿信息、安全提醒；可操作事项同时有明确文字。
2. 最近收藏：已公开当前语言卡片，含名称、说明、分类/平台、最近收藏时间；查看全部进入私有收藏页。
3. 我的贡献：投稿状态及评价修改待审，说明下一步；接受投稿与资源发布明确分开。
4. 通知摘要：未读标记、事件、时间与可操作目标；只有实际未读数才出现数值徽章。

统计卡点击进入对应列表，口径为本人当前有效收藏数、本人投稿数、本人评价主体数、本人未读通知数，不把修订数当评价数。不显示排行、增长百分比、假连续使用天数或不存在的历史。局部查询失败显示“暂时无法读取”，不能显示0；首次使用真实0对应首次使用空状态。某模块未实现显示尚未开放，不能将尚未建表显示为空账户。

原型示例固定为3条收藏、2份投稿、1条评价、2则未读通知；其中收藏含1条不可用占位。贡献摘要显示一份需补充投稿、一份已受理投稿，以及一条修改待审评价；不写评价正文或演示星级，不冒充真实体验。

## 6. 我的收藏

页面头包含“我的收藏 / Saved Skills”、私有说明和浏览资源入口。工具栏为关键词、状态（全部/可用/暂不可用）、分类/平台（来自真实当前可见标签）、排序（最近收藏/名称）；应用和清空筛选均可键盘操作。正文使用Skill卡片网格，底部分页保留筛选与语言；没有批量删除首版需求时不增加危险批量操作。

| 状态 | 内容与可用操作 |
| --- | --- |
| 正常 | 当前完整语言的公开卡片；查看详情、取消收藏。取消发送明确目标状态，成功后移除或给可撤销反馈；重试不反向切换 |
| 缺少当前语言 | “此资源暂无中文版本 / This resource is not available in English”；只有真实可公开替代语言才提供显式切换链接，不伪造翻译或 slug |
| 资源已撤下/不可公开 | 只展示“资源暂不可用”、通用图标和取消收藏；不展示缓存旧标题、作者、仓库、摘要、评分或详情链接 |
| 首次空状态 | “把值得再看的 Skill 留在这里”；主按钮浏览资源；不填演示推荐当个人收藏 |
| 筛选无结果 | 保留筛选，给“清空筛选”；区别于从未收藏 |
| 加载/失败 | 骨架标为忙碌但不播读装饰；失败保留已读内容和重试，不把失败显示成空列表 |

收藏关系跨语言只存一份；恢复收藏不更新首次收藏时间。取消成功需服务端确认，失败保留原卡片和按钮状态；静态原型不模拟写库成功。

## 7. 我的评价与待审编辑

列表使用“全部 / 已公开 / 待审核 / 已撤回”分段筛选，按更新时间分页。每项展示当前可公开Skill、原文语言、公开版本状态、待审修改状态和操作。被隐藏的资源使用不可用占位，用户自己的评价文本只有其本人授权上下文可读，不能因此暴露Skill草稿。

编辑页采用主表单 + 桌面状态说明栏，手机将说明放表单前。星级为1–5整数的可键盘 radio group，评论必填；使用体验、版本/平台、优缺点及限制按真实信息填写，不强迫编造。独立显示“公开版本”和“本次修改”，新稿明确“审核通过前不会替换当前公开内容”。

| 状态 | 用户看到什么 | 可执行动作 |
| --- | --- | --- |
| 首次待审 | “评价待审核”，尚无公开版本、不参与评分 | 编辑生成新修订、撤回；不显示已发布标记 |
| 已公开 | 当前批准修订及原语言 | 编辑、撤回；跨语言进入仍为同一评价 |
| 修改待审 | 原批准版继续公开；新稿单独显示“仅你和审核人员可见” | 查看差异、再次编辑生成新稿、按政策撤回 |
| 新稿被拒绝 | 用户可见理由；旧批准版保持公开 | 修改后重新提交；不能显示内部备注或举报者身份 |
| 首稿被拒绝 | 无公开评分贡献；给明确修改路径 | 查看反馈、修改或撤回 |
| 撤回/管理员隐藏 | 已停止公开与计分 | 查看可见反馈；恢复须重新校验，不允许编辑绕过隐藏 |
| 版本冲突 | “此内容已更新，请先查看最新版本” | 保留未提交文本供复制，加载最新稿；禁止覆盖他人审核结果 |

撤回确认解释公开评价及评分贡献将移除；确认按钮描述行为，取消回原焦点。不要用“购买已验证”“安全认证”等无依据徽章；没有批准评价时显示“暂无评分”，不填5.0。UI 不将 Skill 内容审核或 AI `ai_reviews` 混作社区评价。

## 8. 投稿、更新建议与认领

“我的投稿”显示真实状态筛选、标题/来源线索、最近更新时间、下一步及详情。详情页依次为状态说明、用户可见反馈、当前修订、时间线、操作；内部审核笔记与风控细节不展示。

投稿表单字段：来源类型（GitHub/人工说明）、规范GitHub仓库根URL、可选独立 source_path、说明、目标语言及必要归属/授权说明；更新建议额外显示只读目标Skill与所见版本。路径未知明确“待确认”，不得预填 `SKILL.md`；同仓库不同路径是不同候选。保存私有草稿与提交审核两个按钮含义分明，网页不扫描仓库、不执行代码、不触发付费AI。

| 内部工作流 | 中文 / English | 设计动作 |
| --- | --- | --- |
| draft | 草稿 / Draft | 继续编辑、提交 |
| submitted | 已提交 / Submitted | 查看、允许范围内撤回；不称已受理/已发布 |
| in_review | 审核中 / In review | 查看冻结修订；编辑需产生新修订或按服务规则暂停，不能覆盖审核内容 |
| needs_changes | 需要补充 / Changes requested | 明确缺少内容、修改并重新提交 |
| accepted | 已受理 / Accepted | “已进入编辑流程，尚不代表资源发布”；仅实际公开时提供资源链接 |
| rejected | 未通过 / Not accepted | 查看用户可见原因，按规则修改或结束 |
| withdrawn | 已撤回 / Withdrawn | 保留本人历史，说明不再继续当前处理 |

历史匿名投稿没有本人归属时，不出现在“我的投稿”；帮助入口说明可经人工核实处理，不按相同邮箱自动认领。一个投稿可关联多个实际结果；公开结果链接逐个检查语言及门禁。

认领页先选择作者或维护者，再提交公开证明。界面说明仓库控制权只能支持维护者身份，作者需可核实署名/授权依据；不请求GitHub Token、私钥或身份证。状态包括未提交、待审核、需补充、已核实、拒绝、已撤销/待重新核实；最后两种立即移除对应有效公开关系。认领不提供直接编辑/发布按钮，只提供更新建议入口。

公开开发者资料默认关闭；用户主动申请时单独填写公开显示名、安全handle及真实中英文简介，提示邮箱和登录名不公开。公开预览清楚区分已批准快照与待审修改；资料批准和认领批准是两个独立事实。未提供对应语言的公开简介不复制另一语言充当译文。

## 9. 通知与偏好

通知中心提供全部/未读/账户/投稿/评价分类，通知行包括文字未读标记、事件名称、简短摘要、带时区的时间、查看详情或必要操作。查看后标记已读与批量“全部标为已读”都只更新本人通知；失败保持真实未读数。过期或目标无权读取显示通用不可用说明，不绕过对象权限打开历史数据。

站内事件与邮件状态分开：投稿已受理可以是真实业务结果，即使邮件失败也不回滚；邮件不能用站内已读推断送达。用户可见邮件状态采用排队、重试中、已交给邮件服务、发送失败、结果待确认、已过期等解释性文案；outbox内部标识不成为产品文案。通知正文不带令牌、内部备注、完整邮箱或可公开分享的私有URL。

偏好按站内与可选事务邮件分别配置，并明确必要账户安全邮件的用途。周精选属于单独自愿订阅，默认关闭，之后实施时独立确认/退订；“Subscriber”角色名不进入用户文案，不代表同意营销。语言偏好明确影响界面及新通知/邮件模板，历史UGC保留原文。

## 10. 设置、安全与隐私

| 页面 | 组件与行为 | 重要状态 |
| --- | --- | --- |
| 个人资料 | 显示名、简介、网站、界面语言、本地受控图片头像；保存与取消 | 未保存离开提示、保存中、真实成功、错误/冲突；上传给实际大小/MIME约束，不预设远程头像追踪 |
| 安全 | 密码变更、邮箱变更、注销其他会话；敏感操作近期认证 | 新邮箱待验证时保留当前登录邮箱；验证新地址后才替换；旧链接失效、会话撤销、失败可恢复 |
| 通知偏好 | 必要安全消息说明、可选事务消息、站内设置、语言 | 保存失败不回显为已保存；营销选项独立且默认关闭 |
| 隐私 | 资料可见性、数据导出、删除申请、保留期说明 | 原生隐私申请待确认/处理中/完成/失败；不能即时按钮假称全部清除 |

危险区放页面末尾，与日常保存隔离。删除申请使用清楚的后果页与近期认证：撤销会话/令牌/订阅、停止后续通知、删除收藏/偏好/私人通知、撤下可识别公开评价并重新计分、处理头像和开发者档案；依法/按政策保留的最小去标识化审核事实说明期限与理由。Skill、译文、来源版本及其他用户数据不随删号删除；不将私有投稿重分配给别的账户。

导出只含本人授权资料，下载需要授权和有效期，不进入公开附件目录；进度与完成可见，失败可重试。主题停用不等于隐私删除。原型不收集真实个人资料、不提供真实删除入口。

## 12. 可访问性、原型和后续验收

使用原生链接/按钮/details/表单控件，跳转内容可聚焦，页面一个h1，区域有标题；图标装饰设 `aria-hidden`，图标操作必须有可见文字或准确标签。侧栏当前页用 `aria-current`，未读数与状态均有读屏文案。正文对比度至少4.5:1，大字及必要控件至少3:1；焦点可见，不靠颜色识别状态；尊重 `prefers-reduced-motion`。手机、键盘、200%缩放和400%重排能访问全部内容，不能用hover作为唯一信息来源。

本轮静态验收：

- Dashboard 与共享外壳、页面链接、中文/英文切换一致；所有演示内容可识别，无真实身份成功、邮件送达或写库陈述。
- 320/375/768/1024/1440px核查溢出、触点、长文本与双语换行；所有主要区域可在手机单列阅读。
- 收藏不可用示例不含旧标题/来源；投稿受理明确不等于发布；修改待审明确旧批准版继续公开。
- 键盘可走账户菜单、锚点、卡片、演示按钮；无空href、死链、远程字体/图片或外部请求依赖。
- 原型中的总量能对照示例记录：3收藏、2投稿、1评价、2未读；这些数量不得进入正式产品。

后续实现验收（本轮未执行）：

- 中英分别完成注册→确认验证→登录→资料→重置→退出；错误、过期、重放、限频、发送失败均有真实可恢复结果。
- 未验证和另一账户无法越权；账户枚举、安全返回地址、近期认证和原生旁路共同检查；历史管理员通道保持可用。
- 收藏唯一、重试幂等、缺译及撤下资源不泄露；评价新稿不计分、并发审核拒绝过期修订、撤回立即撤除公开贡献。
- 投稿草稿私有、认领不授权发布、匿名历史不自动归属；所有公开资源仍经PublicCatalog。
- 邮件的排队/传输接受/真实送达独立取证；未做真实SMTP或收件箱测试时保留未执行，不由原型或Mock替代。
- 个人数据导出/擦除、删除账户后的缓存与评分、安全会话、通知及隐私边界独立验收；WPML仍须合法真实环境。
