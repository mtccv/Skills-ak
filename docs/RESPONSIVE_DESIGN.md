## 2. 断点、容器与通用尺寸

断点根据**可用 CSS 视口宽度和内容是否容纳**选择，不判断设备品牌、User-Agent 或“手机 / 平板”硬件类型。桌面缩放后可进入 Mobile 布局；宽屏触屏设备仍须支持触摸。以下英文名只是布局档位。

| 档位 | CSS 视口宽度 | 页面外侧最小 gutter | 布局职责 |
| --- | --- | --- | --- |
| Mobile | `<768px` | 16px | 单主列、完整可换行标题、可折叠导航及筛选、竖排主要操作 |
| Tablet | `768–1023px` | 24px | 公共资源两列；主要阅读和编辑单列；次级导航折叠 |
| Desktop | `≥1024px` | 32px | 完整导航、必要侧栏与多列内容；1024 本身也必须可用 |
| 列表密度调整 | `≥1280px` | 延续 Desktop | 仅在有 240px 筛选侧栏的资源列表将结果从两列增为三列，不创建第四种导航模式 |

内容区域宽度为 `min(1280px, 100% - 2 × gutter)`；**1280 是内容本身上限，不含两侧 gutter**。1440 视口的内容居中后两侧各 80px，1920 各 320px。正文建议上限 72ch；账户表单上限 640px，认证卡片上限 480px。小屏取消固定最小宽度，所有 grid / flex 子项允许 `min-width: 0`，不要使用 `width: 100vw` 造成滚动条溢出。

| token / 对象 | 规则 |
| --- | --- |
| 品牌与表面 | 浅色系统；主紫 `#7047EB`；正文 / muted / border / 状态色遵循共享设计系统，正常文字至少 4.5:1，大字与必要图形至少 3:1；不能仅凭颜色表示选中、成功或风险 |
| 圆角 | 卡片 16px，按钮 10px；输入框、标签等按设计系统各自 token，不把所有组件强行同圆角 |
| 布局间距 | 列表 / 用户中心侧栏 gap 24px；阅读主列与事实侧栏可用 32px；平板卡片 gap 20px；手机 gap 16px；内容区块纵距可随档位从 64 / 48 / 32px 收缩 |
| 触点 | 独立按钮、图标、语言入口、分页、可点击 chip、关闭按钮至少 44×44px；文字链接行高 / 内边距或透明点击区补足，不造成相邻命中区重叠 |
| 文字 | 正文 / 输入字号以 16px 为基准；次要元数据可以 14px，但不能用 10–12px 装下关键状态；页面H1按设计系统42 / 30–32px、Hero按56 / 48 / 36px，允许自然增高 |
| 图片 / 图形 | `max-inline-size: 100%`，保持比例；声明尺寸避免跳动；头像不挤压名称；装饰隐藏不改变信息顺序 |
| 横向滚动 | 只用于确需二维阅读的代码或复杂表格，设置独立可辨认边界、名称和键盘访问；页面本身不得左右滚动 |

上表的 1280 容器、紫色、字体及圆角适用于公共前台和用户中心。原生后台沿用 WordPress 的内容宽度、蓝色操作、字体与圆角，不用前台视觉 token 全局覆盖 wp-admin；后台具体值由后台设计规范负责。44px 独立交互目标、可见焦点、重排和长内容可读性是共同设计目标：对 Hub 自有控件在其作用域内实现；无法满足的原生控件须列出实际验收差距，不能默认通过。

这些是设计 token，不是本轮要求修改生产 Tailwind 配置的指令。后续需统一更新源码与构建物，避免只改 `dist`。

## 3. 导航、侧栏、折叠与 sticky

### 3.1 公共壳层

Desktop：Logo → 主导航 → 语言 → 账户 / 投稿入口。导航当前项有文字与 `aria-current`；1024 下若长英文标签占满空间，优先减少导航间距并将次要操作收到有标签的“更多”，禁止靠缩小触点或压掉语言切换解决。Tablet / Mobile：Logo、语言与“菜单”保持可见；主导航及账户 / 投稿在同一折叠区域中。搜索在列表工具区或首页 Hero 保留，不用只有 hover 才出现的搜索入口。

公共前台与用户中心原型的菜单 / 筛选采用原生 `details/summary` **内联折叠**，展开推动页面内容；summary 有文字、展开状态及 44px 触点；菜单链接不套用应用型 `role="menu"`。内联内容不使用模态遮罩、不锁住背景、不 trap focus。Escape 可作为增强关闭并把焦点交还 summary；无 JS 仍能开关及访问链接。后台原型使用按钮控制原生风格侧栏，其键盘及无 JS 行为单独验收，不套用前台 details 的保证。

若后续采用遮罩抽屉，必须另实现并验收：有名称的 dialog、打开时焦点移入、背景 inert、Tab 在抽屉中循环、Escape / 关闭按钮可退出、关闭后焦点回触发器；跨断点收起时清理滚动锁与 inert，确保焦点不落入隐藏区域。筛选的“应用”才提交；“取消 / 关闭”不偷偷变更结果。这个合同不表示静态原型已经实现抽屉。

Footer：Desktop 为品牌说明与三组链接共四列；Tablet 在内容可容纳时保留四列，长文案或放大后自然减列；Mobile 单列。探索、社区、帮助 / 政策按组保留标题。移动不隐藏政策、联系、语言或退订等入口，不以过深折叠降低可达性。

### 3.2 用户中心和后台壳层

用户中心 Desktop 使用 240px 侧栏；Tablet / Mobile 使用标题明确的“个人中心导航 / Account navigation”内联折叠，当前页面名称始终可见。收藏、投稿、评价、通知的数量只显示真实数据；尚未交付的模块显示“尚未开放”或没有可操作入口。无需常驻底部图标导航来重复已有菜单。

后台保持 WordPress 原生顶栏、左导航、通知、分页及能力控制。WordPress 自有的导航折叠阈值（包括常见 782px 行为）不是本设计 768 / 1024 档位的冲突，不覆盖 Core 断点。Hub 面板根据扣除原生导航后的可用宽度决定列数；无空间时先堆叠，即使整个窗口超过 1024。

### 3.3 固定元素与遮挡

默认文档流优先。若启用 sticky 公共导航或桌面目录，offset 包含实际 header 高度及登录后的 WordPress admin bar；不能硬编码一个只适合访客的 top。目录 sticky 仅在 Desktop 且可视高度足够时启用；过高侧栏回到文档流，不新增难操作的嵌套滚动。

锚点和聚焦目标需有对应 `scroll-margin-block-start`；跳过导航链接仍在最高可交互层。Tablet / Mobile 不将来源卡、筛选或提交按钮永久浮在内容上；任何后续 sticky 保存条都要为正文预留自身高度及 `env(safe-area-inset-bottom)`，在软键盘打开、横屏短高度、200% / 400% 缩放时仍能见到当前字段、错误、焦点和提交操作。不能同时堆叠顶栏、tabs、筛选和底栏占满视口。

### 8.1 中文、英文与极端内容

- 真实中文及英文逐页检查；`html lang` 与界面一致，混排的已知其他语言段落可设置 `lang`。中文允许自然断行，避免对所有文本 `word-break:break-all`；英文通常按单词换行，长标识 / URL 使用 `overflow-wrap:anywhere` 兜底。名称、标题、错误、来源路径和状态不设只适合中文的固定高度。
- 长英文标签预留约 30%–50% 扩展测试空间；真实上限输入仍按服务端合同。中文正文、无空格英文长词、2048 字符 URL、长 repository/source_path、64 字符 SHA、多标签都应独立测。显示可省略的简介与必须完整的风险 / 法律 / 错误文案分开；不能只靠 tooltip 补上必读文本。
- code block 保留空白与命令原文，在自身区域水平滚动；不要为适配手机插入会改变复制结果的换行 / 省略号。inline code 可视觉换行。表格、数学或代码的二维例外不允许扩散到整页。
- 已发布 Skill 仍共用稳定 ID；切语言保留合法筛选并回第一页。缺译明确提示并链接到真实可用语言或目标语言列表，不复制原语言冒充译文；无真实对应内容不造 `hreflang`。UGC 保留原语言标识，不因切界面语言创建第二条评价。

### 8.2 键盘、读屏、触屏与视觉偏好

- 从 skip link 到主导航、主要表单、内容和页脚，Tab 顺序符合阅读顺序；每页一个 H1、分级 H2/H3 和唯一 main。重复 nav 分别命名；图标按钮有可访问名称；当前语言 / 当前页 / 当前筛选有语义状态。
- focus-visible 始终清楚，至少 2px 外框并有适当 offset；卡片 overflow、sticky、滚动容器及 dialog 不裁掉焦点。打开 / 关闭、保存 / 失败、列表更新与跨断点变换后，焦点留在可见且合理的位置。
- 触屏、触控板与鼠标功能一致；关键操作常显或点击展开。装饰 hover 效果仅在 `(hover:hover) and (pointer:fine)` 下增强；不得要求悬停才能看到编辑、举报、关闭或提示。拖拽 / swipe 若引入，必须有按钮替代。
- `prefers-reduced-motion:reduce` 取消平滑滚动、位移和循环动画；加载仍有静态文字。不得通过动画表达唯一状态，不引入自动播放轮播。
- `forced-colors:active` 保留系统文字、边框、focus 与选中标记；按钮和输入轮廓不能只靠阴影 / 背景色。选择状态有文字 / 图形，图标使用可适配的 `currentColor`；不得通过全局关闭 forced colors 保品牌色。
- 允许浏览器缩放；viewport 不设 `user-scalable=no` 或限制 maximum-scale。200% 文字放大仍有完整功能；400% 缩放按实际 CSS 视口进入小屏布局，不把鼠标设备强留 Desktop。

### 8.3 打印

阅读页、安装指南和政策页打印时使用单列黑字白底，隐藏导航、纯装饰和无纸面意义的操作，取消 sticky / fixed 与正文最大高度 / overflow 裁切。文章标题、来源、许可证、风险与已有内容保留；代码可按打印宽度换行但屏幕复制原文不变；表头可重复，避免标题孤立和卡片内容跨页截断。公开链接可显示目的地址，私有页面不要自动打印令牌、内部备注或不属于当前内容的隐藏面板。账户 / 后台仅打印当前授权可见区域；打印布局不能绕过权限。
