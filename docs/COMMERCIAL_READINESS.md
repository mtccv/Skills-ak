# Phase 13：先免费运营的商业化能力预留

主题/Core 0.13.0，schema 1.9.0，33 张 Core 表保持。本阶段提供人工展示和业务扩展边界，不售卖会员、不建立订单、扣费、付费墙或主题联网授权。部署或升级不会创建赞助商、客户、素材、套装或演示统计；现有免费浏览、搜索、账户、收藏、评价和投稿规则保持。

## 复用与入口

| 能力 | 复用 | 新增范围 |
|---|---|---|
| 赞助 | 原生非 autoload options、既有首页/详情组件、PublicCatalog、workflow_events | 有限位置和条目、双语人工素材、时间窗、独立开关、审核确认、修订冲突及操作记录 |
| 免费权益 | WordPress Users、AccountService、原有 Capability | 只读的当前用户资格查询；不授予能力，不替代服务端对象/内容/Nonce检查 |
| 资源套装 | 既有编辑集合、原 Skill ID、当前语言发布门禁 | 有界人工选中的集合入口和说明，不复制资源或创建商品 |
| 企业咨询 | Contact、私有 aish_message / postmeta、原有限流、工作流审计与隐私处理 | 独立 enterprise 类型和处理权限、真实双语服务说明、私有人工处理 |
| 最小指标 | metric_events / daily_metrics、现有短期观察凭证 | 赞助展示/点击与真实收到咨询的独立汇总；不修改自然排行的指标和权重 |

不创建空的 `/sponsors/`、`/original-skills/`、`/bundles/` 或结账页。套装使用已经存在的集合地址，企业说明使用对应语言 Contact 页面；这些是复用入口的实现选择，不是缺失翻译或虚构内容的占位页面。新增预留不会为 Sitemap 生成额外空条目。

## 默认免费与手动启用

赞助和企业说明初始关闭，套装入口初始为空。管理员须先填写实际可核实内容、审核并明确启用。普通投稿审核权限不包含赞助配置、商业汇总或咨询隐私。后台沿用 WordPress 原生菜单、表单和表格，所有状态用文字说明；前台延续白灰、深灰及少量陶土棕强调。

赞助展示永远标明“赞助 / Sponsored”，不会成为“编辑精选”、作者认证、安全认证或内容审核结果。生效开始边界包含、结束边界不包含，统一 UTC；暂停/到期即时作用于展示，不依赖 Cron。引用 Skill 时再次核对当前语言的公开条件，缺译、归档或撤销审核不能经赞助继续公开。

只接受受控文本、合法目标链接及受限本地媒体。素材权利须人工核实，不接受脚本、跟踪像素或可执行模板，不自动下载或扫描链接。配置赞助不启动 GitHub 或 AI 任务。链接正常导航，不使用接受任意目标参数的跳转接口。

### 具体配置与权限

| 原生后台入口 | Capability | 边界 |
|---|---|---|
| 赞助展示 | `aish_manage_sponsors` | 全局默认关闭；最多20条人工记录，每个固定位置最多2条实际展示 |
| 赞助展示统计 | `aish_view_commercial_metrics` | 仅聚合数字，无个人记录、咨询正文和联系方式 |
| 企业咨询 | `aish_manage_enterprise` | 真实双语说明开关、私有咨询列表及人工处理 |
| 资源套装 | 既有 `aish_manage_discovery` | 最多12个既有集合ID，不授予赞助或咨询权限 |

三个新增能力默认只授予已有 administrator；首次后台请求在菜单注册前安装能力，其他角色须单独授权。没有权益授权配置器。赞助仅有 `home_after_search`、`skill_detail_footer` 两个预设位置；内部目标必须使用 Skill ID，外链不接受本站地址绕过资源公开检查。中文/英文标题与简介各自维护，缺译语言不展示。图片只能引用受控本地公开栅格媒体及核实说明，无外部素材抓取；文本标识可不带图片。

赞助保存支持 draft/enabled/paused，scheduled/expired 按实际UTC时间计算；启用条目必须有完整内容、结束时间和人工审核确认。全局展示开关与条目状态分开。保存使用预期修订，冲突刷新后再确认；操作和配置同事务写入审计，不能重复请求生成多个记录。预览留在受权限保护的原生后台，不成为公开地址或统计观测。

企业说明按语言人工填写并启用；咨询支持 pending/reviewing/closed/archived，带修订和内部处理备注。Contact的原表单继续可用，企业表单为独立类型，不将咨询改为会员投稿。默认没有服务说明或示例合作案例。

## 原创与套装的证据边界

现有人工录入和人工审核继续承担资源生产。套装只组织现有公开资源，不推断网站拥有资源版权，不代表所有成员具备商业再分发许可。身份与许可必须逐项核对；已有经审核的原创作者关联也不等于网站拥有该作品。来源或许可不明时保持待核实，不凭管理员勾选生成“AI Skills Hub 原创”“可商用”认证。

没有真实成员或当前语言公开内容时不显示套装入口。成员下架后的下一次请求按原 PublicCatalog 条件过滤；收藏、评价、版本、双语和 Skill ID 仍为同一套事实。

## 企业咨询与个人信息

企业说明必须由管理员填写真实可提供的服务，两种语言分别维护。咨询只收集必要联系信息和需求，进入原私有 Inbox 的独立类型。收到咨询不表示订单成立、合同签订、报价或服务交付，不自动收费、发营销邮件、触发外部 API 或导入营销名单。

后台单独授权，普通用户不能读取他人咨询，普通投稿审核人员也不会自动获得读取权限。处理记录和内部备注不进入公开页面或指标。Contact 与会员投稿继续采用各自原来的身份规则；匿名咨询不因此认领历史投稿或成为已验证用户。

## 统计与同意

实际启用展示后，仍需访客明确同意相应观察用途才采集展示/点击。此前只授权浏览或搜索的 Cookie 不自动扩大到赞助计量；沿用同一个短期随机凭证，不新增个人身份或跨站追踪。撤回观察同意停止共享凭证下的计量。

有效展示要求至少50%组件进入视口、页面可见且有焦点累计1秒；点击来自正常链接交互，链接不等待统计请求。每个签名页面响应/观察主体/事件最多记录一次，另按条目/位置、语言、指标、观察主体及UTC日计算去重值。两个口径分别展示，重复请求不会重复加总。它们是受控观察次数，不等于所有页面请求、所有点击、真实独立人类、购买或收入。实际收到的咨询以私有存储中的有效记录计量，与点击分别展示，不能推导成交率。

不记录原始 IP、完整 User-Agent、完整请求 URL、查询词或用户个人行为列表。聚合数据只向授权运营人员开放；统计失败不阻断页面或链接。无真实事件时显示未采集/零值/不可用的实际区别，不回填历史，不创建收入或付费用户数字。

指标政策为 `commercial-1`，`sponsor_impression` / `sponsor_click` 与对应 `_unique` 日桶独立于 `skill_view`。7或30日窗口**包含今天的未完整UTC日**，界面显示实际刷新时刻；与Phase12完整UTC日报表不要直接相除。每个观察主体每天最多100次、全站每天最多10,000次展示/点击观测，触及上限标明覆盖受限。去重事件7日、日聚合400日，预算次日到期；复用有界维护Cron分批清理，调度中断会延长实际物理保留。未采集、查询失败、部分覆盖和实际零值分别说明。

## 免费权益接口

Core服务 `commercial_entitlements` 提供 `eligibility($feature)`，返回 `eligible`、`source=free-1`、固定原因及 `object_authorization_required=true`。支持 browse/search/favorite/review/submit/profile_read/profile_edit/account_security，使用当前会话，不接受请求中的user_id、plan或role授予权限。`manages($area)`只查询固定管理领域的原生Capability。未来扩展不能把这个预检结果当作写入授权；原业务仍必须在操作时核对当前账户、邮箱验证、对象归属、公开条件、Nonce和事务。未验证用户的既有恢复入口保持。
